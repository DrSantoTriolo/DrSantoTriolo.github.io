Welcome! This is my new minimal blog where I'll share technical writing, debugging adventures, and tutorials.

I built this space to document my learning journey and share solutions to problems I encounter. Whether it's a tricky bug, an interesting algorithm, or a useful tutorial, you'll find it here.

## What to Expect

I'll be writing about:

- **Technical Deep Dives**: Exploring how things work under the hood
- **Debugging Stories**: Real-world problems and their solutions
- **Tutorials**: Step-by-step guides for building things
- **Best Practices**: Lessons learned from experience

## Why I'm Blogging

Writing helps me:

1. Solidify my understanding of concepts
2. Create a reference for future me
3. Help others who might face similar challenges
4. Build in public and share the journey

## Example: Code Snippets

Here's how code looks on this blog:

```javascript
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

console.log(fibonacci(10)); // 55
```

And inline code looks like this: `const greeting = "Hello, World!";`
