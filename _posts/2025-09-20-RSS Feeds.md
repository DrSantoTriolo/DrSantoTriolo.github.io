Below are simple, free ways to follow “as many RSS feeds as you want” and organize them in folders. I’ve ordered them from “fastest to set up on your own computer” to “fully web-based via self‑hosting” (which scales best if you truly want thousands of feeds). Each includes step‑by‑step setup and key trade‑offs.

Option 1 — Thunderbird (Windows/macOS/Linux, desktop-only)
What it is: Mozilla’s free mail app also has a solid RSS reader with folders and OPML import/export. No account limits because everything is local.
How to set it up (5–10 minutes)

Install Thunderbird.
Create a Feed account: in Thunderbird, add a “Feed” account (Blogs & News Feeds).
Add feeds: select the Feed account in the sidebar, click “Manage subscriptions,” paste a feed URL, click Add. Repeat. (support.mozilla.org)
Organize folders: right‑click the Feed account → New Folder (you can nest subfolders). Drag feeds between folders as you like. (support.mozilla.org)
Optional: import an OPML file so you don’t add feeds one-by-one (Feed Subscriptions → Import). (support.mozilla.org) Trade‑offs
Pros: Free, no server, no feed caps; great foldering and OPML import/export. (support.mozilla.org)
Cons: Desktop‑only (no built‑in mobile sync); UI is email‑centric; syncing across devices requires your own workaround (e.g., profile sync or a third‑party reader).
Option 2 — RSS Guard (Windows/macOS/Linux; desktop, but can sync to services)
What it is: A free, open‑source reader that supports a local “Standard” account (no caps) and can also sync with services (FreshRSS, Tiny Tiny RSS, Inoreader, etc.). Organizes with “Categories” (folders). (rssguard.readthedocs.io)
How to set it up (5–10 minutes)

Install RSS Guard (download from the official site, your distro’s repo, or Flathub). (rssguard.readthedocs.io)
On first launch, add an account: choose “Standard” (local) for unlimited local feeds.
Create folders: click “Add a new category” and (optionally) choose a parent to nest it. (virtualcuriosities.com)
Add feeds: click “Add subscription,” paste each RSS/Atom/JSON URL, and assign it to a category. (rssguard.readthedocs.io)
Optional: Import OPML (File → Import) and tweak filters/tags if you want power features. (rssguard.readthedocs.io) Trade‑offs
Pros: Free, cross‑platform, categories (folders), powerful filters/tags; can be local only or sync with many backends. (rssguard.readthedocs.io)
Cons: Desktop app (no built‑in cloud service); UI is powerful but more “utility” than slick.
Option 3 — Fluent Reader (Windows/macOS/Linux; desktop, modern UI)
What it is: A modern, open‑source desktop reader that organizes subscriptions with “Groups” (folder‑like). Works entirely locally (no caps) and can also sync with services compatible with Fever/Google Reader API, Inoreader, Feedbin, etc. (github.com)
How to set it up (5 minutes)

Install Fluent Reader (GitHub Releases or Flathub). (github.com)
Add sources: import an OPML or paste feed URLs (Settings → Sources). (hyliu.me)
Make folders: create “Groups” and assign feeds to them in settings. (github.com)
Optional: enable rules to auto‑star/hide/mark read by keyword, and use the built‑in full‑content view. (hyliu.me) Trade‑offs
Pros: Free, fast, polished UI; no account limits locally; optional syncing via open APIs. (github.com)
Cons: Desktop‑only; if you want cross‑device sync, you’ll pair it with a self‑hosted backend (below).
Option 4 — FreshRSS (self‑hosted, web app; scales to huge libraries)
What it is: A free, self‑hosted web reader with folders (categories), OPML import/export, and an API used by many mobile/desktop clients. Designed to handle very large libraries (tens of thousands of feeds; millions of articles). (freshrss.org)
How to set it up with Docker (15–30 minutes)

Install Docker (and Docker Compose) on any machine (home server, VPS, NAS).
Start FreshRSS via Docker. Example (linuxserver image):
Create a folder for config, then run a compose or “docker run” based on the image’s readme. Map port 80 (or 8080) and a config volume; start the container. (github.com)
Finish the web installer: open http://YOURHOST:PORT, choose SQLite (simplest), create an admin, complete setup. (github.com)
Add feeds and folders: in the web UI, subscribe by URL and assign a “Category” (folder), or bulk‑import OPML. (freshrss.org)
Turn on automatic refresh: set the built‑in cron with the CRON_MIN env variable (e.g., 13,43) or schedule a host cron to run FreshRSS’s update script every ~20–30 minutes. (freshrss.github.io) Trade‑offs
Pros: Completely free; you control your data; built for scale; categories/folders; OPML; many clients can sync to it (Google Reader/Fever‑compatible). (freshrss.org)
Cons: Requires a server and light maintenance; you must configure updates (cron) so feeds refresh automatically. (freshrss.github.io)
Option 5 — Tiny Tiny RSS (tt‑rss) (self‑hosted, web app; advanced features)
What it is: A long‑standing, feature‑rich, self‑hosted reader. Supports folders (and subfolders), filters, labels, sharing, OPML, and a JSON API. Official deployment is Docker‑based. (tt-rss.org)
How to set it up with Docker (15–30 minutes)

Install Docker (and Docker Compose).
Grab tt‑rss’s Docker setup (.env and docker‑compose.yml), set your URL (SELF_URL_PATH), and start it: “docker compose up -d.” (tt-rss.org)
Open the site in your browser, log in, and subscribe to feeds; create categories to organize them. (maketecheasier.com)
Optional: add plugins/themes; tt‑rss supports powerful content filters and generated/published feeds. (tt-rss.org) Trade‑offs
Pros: Free; very flexible; folders and subfolders; powerful filtering/sharing; lots of plugins. (tt-rss.org)
Cons: Needs a server and ongoing updates; the official Docker images target x86_64 (ARM requires self‑built images). (tt-rss.org)
Optional if you already run Nextcloud — Nextcloud News app
What it is: If you have a Nextcloud server, add the News app to get a web reader with folders, plus Android/iOS clients. (github.com)
How to set it up

In Nextcloud → Apps, install “News.”
In the News app, add feed URLs; use the “Folder” field to organize feeds. (nextcloud.github.io) Trade‑offs
Pros: Free and integrated with your cloud; folders; API; mobile apps exist.
Cons: Only if your host allows installing the News app (some free Nextcloud providers restrict apps). (help.nextcloud.com)
Which one should you pick?

“Fastest and simplest, no server:” Thunderbird, RSS Guard, or Fluent Reader.
“I truly want unlimited and cross‑device:” self‑host FreshRSS or Tiny Tiny RSS and connect your favorite clients to them.
“I already use Nextcloud:” install the News app.
Notes on hosted web readers (Feedly, Inoreader)

These are convenient but their free plans cap the number of sources, so they don’t meet your “as many as I want” requirement without paying. For example, Inoreader Free allows up to 150 feeds (Pro lifts the cap), and Feedly Free has historically been limited to around 100 sources. (jp.inoreader.com)
Quick tips that help regardless of option

Always export an OPML backup after importing a big library, so you can switch apps in minutes. (Supported by Thunderbird, Fluent Reader, FreshRSS, tt‑rss.) (support.mozilla.org)
For huge libraries, favor a self‑hosted web reader (FreshRSS/tt‑rss). They’re built to handle very large numbers of feeds and articles. (freshrss.org)
